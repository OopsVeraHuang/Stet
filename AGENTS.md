# Prototype workspace rules

- This is the PUBLIC-CANDIDATE prototype workspace. Build here, never modify the private companion deployment.
- Read README, docs/01-project.md, docs/02-architecture.md, docs/04-roadmap.md and NEXT_AGENT before implementation.
- Existing reference modules are partial extractions, not a working application. Do not label planned capabilities implemented.
- Use synthetic fixtures by default. Never copy private chat databases, source archives, persona examples, receipts, keys, session/OAuth credentials, deployment scripts, voice samples or full copyrighted reading/tutorial files.
- The local-only handoff may identify private source code for read-only inspection. Such access is not permission to publish its contents.
- No production connections, paid calls, external uploads or provider sign-in are needed for the first slice. Finish an offline import/retrieval/correction demonstration first.
- Give the owner plain Chinese explanations: what changed, what she can click, what a result proves and does not prove. Explain one engineering concept at a time.
- Keep research design and evaluation transparent; synthetic tests do not establish personality persistence or a successful user study.
- Do not claim perfect memory, guaranteed stable persona, or all-format automatic import. Unknown speaker/time remains unknown; derived indexes never overwrite originals.
- Keep recorded time distinct from event time, inferred characteristics distinct from user permission, and style continuity distinct from unquestioning agreement.
- No destructive memory migration or blanket disabling of original integrity checks. Changes must be reviewable, tested and reversible.
- No inherited personal endpoints, accounts, preferences or secret values in examples/defaults. Runtime user data belongs outside Git.
- The shared repository is not shared SQLite state. Every install/profile must have separate state and credentials; authentication is required before remote deployment.
- Update docs/status.md after each milestone. Do not publish this repository or apply a license without an explicit release decision.
