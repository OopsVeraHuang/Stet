# 开源与数据边界

本阶段建立本地 Git 与项目所有者指定的私有 GitHub 仓库同步流程，保留已有提交历史。私有上传不等于公开开源，也不等于运行服务。上传是否完成以交付核验记录为准。开放源代码不等于公开任何使用者的记忆；示例数据必须虚构或有明确可再分发授权。

此包未附项目整体 LICENSE。先确认代码归属与第三方依赖清单，再由项目所有者选择许可证。不能因为依赖开源，就推断整套素材和模型权重都可以任意再发布。

来源说明：reference_core 来自先导系统的 Python 实现，由作者与 AI 编码助手迭代，已替换个人称呼及私有环境变量名。原始和整理后文件哈希在 provenance.json。没有第三方模型权重、供应商 SDK 源码、教程 PDF、论文全文、商业电子书或影视声音素材。

后续语义模型候选：Sentence Transformers 的 paraphrase-multilingual-MiniLM-L12-v2 及其 ONNX 转换。下载前核对官方模型卡、具体 revision、文件哈希、许可证、运行依赖；仅在本地部署权重。核心包不自动下载。当前参考路径需要 NumPy、ONNX Runtime、tokenizers，未在本仓库建立可发布的依赖锁文件。

发布门槛：全新环境安装通过；无真实凭证与私人标识；测试样本无真实聊天；运行态数据与 Git 分离；模型/依赖归属明确；失败和费用可见；至少一次删除/导出/备份恢复测试；检查完整 Git 历史与 zip 成员，不只检查工作区。

上述是未来完整应用的公开发布门槛，不表示 P0 已经通过安装、数据恢复或设备端到端测试。当前上传只包含起步包，必须先通过现有离线测试、精确字节校验及全部可达 Git 历史的隐私检查；打包方法见 `docs/09-verification.md`。

多用户托管需要单独做账户、隔离、传输、速率与工具权限设计。P1 默认单用户自部署；不可把单用户进程开放到公网就称为安全的多人平台。
