# 不能混淆的三种状态

“私人先导系统具备”来自本地代码及工程记录检查，不代表本次重新完成了所有线上端到端测试。

| 能力 | 私人先导系统 | 此交接仓库 |
|---|---|---|
| 自动混合记忆、短窗口、时间提示 | 有代码与使用经验 | 四个参考模块，需新后端适配 |
| 多模型与工具 | 有供应商适配与工具编排 | 架构说明；未复制私人配置/认证 |
| 历史记录导入 | 有针对特定档案的一次性流程 | P1-A 规范 JSON/MD 预览、确认导入与出处已实现；平台导出适配待做 |
| 明确修正与撤回 | 有实现 | 数据契约与验收要求；需移植 |
| 三类时间与相对时间组装 | 原有时间提示提供经验 | 新契约及合成验收规格；尚未实现组装器 |
| global/topical 纠正联动与成组预算 | 不能由旧策略推定完整支持 | P1-B 待实现；本次只明确契约与验收条件 |
| 阅读器、资料库、学习笔记 | 有实现 | 场景与路线；未打包私人资料和界面 |
| 视频与观察 | 有实验性实现和故障修复记录 | 后续阶段；未包含音频或视频资产 |
| 跨模型人格稳定 | 设计目标 | 研究问题；没有宣称验证完成 |
| 开源即装即用 | 尚未产品化 | P1-A 本机切片可运行；完整应用与公开发布未完成 |

新窗口完成一个功能后，应补充实现位置、测试命令、验证环境和剩余限制，再改变这里的状态。

## P1-A 可运行范围

`continuity/` 提供原文件字节保留、规范导入、分支身份隔离、字面检索与出处下载。可撤销整批导入、检查剩余消息/索引、重建索引；这不是纠正撤回机制。`event_time_note` 与治理扩展字段只原样保留，不推断、不生效。25 项标准库测试及虚构浏览器流程通过；运行环境和局限见 `docs/status.md` 与 `docs/11-p1a-workbench.md`。
