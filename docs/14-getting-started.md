# Stet · 使用指南

**Let it stand.** 保留原话，也保留重新理解它的权利。Stet 原名 Continuity；这是可自托管的交互平台预览版，不是由项目方提供账号的在线服务。

## 1. 安装与启动

下载仓库或经校验的体验包，解压到新文件夹。需要 Python 3.11+；本次验收使用 3.12。第一次安装需要网络下载依赖，不会下载语义模型或调用付费模型。

Windows PowerShell：
```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m continuity --open
```
Linux / macOS：
```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m continuity --open
```

安装好后可双击「启动原型.cmd」，或者再次执行最后一行。终端显示本机网址，默认端口 8780。保持服务运行；Ctrl+C 停止。端口占用时加 `--port 0`，打开新显示的网址。

改名不移动旧数据：Python 入口仍叫 `continuity`，默认资料目录仍为 `~/.continuity/default`。可用 `--data-dir <自己的路径>` 创建独立档案；不要将两人指向同一个目录。备份时先停止服务，再复制整个资料目录。代码包不包含你的资料。

## 2. 先不用 API，走一遍

1. 从侧栏底部选择「简体中文 / English」。只改变界面，不翻译聊天、原件、笔记或已保存偏好。
2. 「导入历史记录」→「预览 JSON 示例」→检查→「确认导入」。示例是虚构的。
3. 在「记忆」搜索示例里的词，打开出处，检查原文件、说话人、时间和分支。
4. 「书架」导入 PDF / EPUB；「资料库」导入 PDF / DOCX / TXT / MD。导入和翻页不调用模型。扫描件暂不 OCR。
5. 有聊天后，开启「学习模式」，右键或长按消息收藏。笔记栏可搜索摘录及评论，支持加粗、高亮、评论、回到原对话、回收站及恢复。笔记共用现有记忆系统，没有另建一套副本档案。

## 3. 导入自己在其他平台的记录

先通过原平台官方导出功能取得文件，不需要在 Stet 登录那个平台。

| 文件 | 实际读取的内容 | 注意 |
|---|---|---|
| ChatGPT `conversations.json`，或包含该文件的 ZIP | `mapping` 的父节点链、角色、文字、消息时间、可用的模型字段 | 不同叶分支分开保存，共同前缀可能出现在多个分支；不擅自拼接两条答案 |
| Claude `conversations.json`，或包含该文件的 ZIP | `chat_messages`，human/assistant，text 或 text 内容块，created_at | 没有分支/时间时保持未知；附件只报告，不导入 |
| Gemini Google Takeout `MyActivity.json` 或 ZIP | Gemini Apps / Bard 活动的 title、time | 常常只有提问，不能恢复导出里不存在的回复；每条活动独立，不猜所属会话。请选择 JSON 导出，HTML 不支持 |
| Google AI Studio JSON | `chunkedPrompt.chunks` 的 user/model 与文字 | 不冒充 Gemini App 完整备份；没有稳定会话 ID 时使用文件内容身份，更新文件可能形成另一来源 |
| Stet / 原 Continuity 规范 JSON、MD | 带显式角色/来源/时间的记录 | 旧 `Continuity transcript v1` 模板继续兼容；普通随意排版 MD 不会自动猜角色 |

上限 32 MiB 文件、20,000 条展开后的消息。ZIP 只读取一个已识别的对话 JSON，不解压到磁盘、不读取其他附件；多个候选文件时请手动解压并选择一个。大导出请按会话拆分，避免截断 JSON 或删除分支关系。

导入先预览：支持的文字、未知字段、非文字内容遗漏均显示；原文件字节完整保存。图像、音频、工具结构和部分附件不会成为可检索正文。未知格式会拒绝，不默默当成成功。预览前 200 条，检查统计覆盖全部记录。确认为零条可读文字时不会导入。

「查看出处」可下载原字节。重复文件不会重复保存；同一身份但内容有冲突则拒绝覆盖。撤销整批导入会删除本应用保存的那批原件和独有记录；外部原文件不变。平台导出结构可能更新，有提示时请保留文件并报告结构，不要把私人导出上传到公开 issue。

## 4. 连接模型与观察费用

进入「连接与预算」：
- **模型与连接**：填自己的 Gemini 或 DeepSeek key，保存，再明确勾选允许 API 请求并保存。密钥不要发到聊天里。GPT 订阅桥在此预览版尚未配置。
- **回答与记忆**：调整检索原文份量、Gemini 思考和输出额度、自动澄清。
- **伙伴与偏好**：自己定义名字、称呼、关系和交互方式，不预置别人的人格。
- **联网工具**：可选 Tavily key，并单独启用。费用与模型阅读结果的费用分别记录。
- **费用与预算**：价格表是历史快照，使用前与供应商核对；CNY 显示不因切英语而变成 USD。预算拦截是可选的，不是充值或订阅。

在聊天框选择模型并发送。连接检查只证明模型信息可访问，不保证生成成功。当前消息和选入的记忆/附件可能发送给你选择的服务商；本地搜索与笔记收藏本身不收费。不要假定缓存免费或某个 API 永久可用。

## 5. 测试中与尚未开放

**视频 Beta** 先本地预览，再明确开始通话；真实设备、网络、供应商模型支持需要自己试用。原始音视频不保存，只保留确认文字/观察记录。锁屏、切 App 或离开页面会结束通话。没有克隆声音。工作室入口暂时隐藏。

默认只监听本机：手机无法访问电脑的 `127.0.0.1`。远程使用需要另行设置认证、HTTPS、独立数据目录；不要直接暴露无保护端口。浏览器「安装为应用」是网页快捷入口，服务关闭后不会继续运行。

本版本有原文检索、可选多语言向量检索及现有澄清机制；**Memory-R2 训练、个性化检索策略和 Alicia 式画像层还是设计稿**。不承诺人格永久稳定。遇到问题，优先记录页面、步骤、错误信息和版本，勿附 key 或完整私人档案。
