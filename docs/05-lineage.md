# 从私人先导系统继承的经验

这是重新撰写的工程摘要，不含原始更新文档、聊天引文或账单。

2026-10-25 补充：完整平台代码已净化迁入 `app/`，不再只有四个参考模块。来源哈希见 `provenance-platform.json`；StarHub 两份教程的标题、设计启发与待补署名信息保留在 `THIRD_PARTY.md`。排除教程全文不等于删除来源致谢。

| 经验主题 | 可复用原则 | 不应夸大的结论 |
|---|---|---|
| 历史迁移 | 保留原文、来源、说话人和分支；提取失败显式列出 | MD 与 Word 不一定等价；颜色角色不是通用约定 |
| 自动记忆 | 每轮本地召回与模型自主补查结合 | 不是“模型已经读完所有资料” |
| 修正层 | 明确纠正有出处、状态和撤回；原文不被重写 | 注入纠正不保证每个模型都完全服从 |
| 多模型 | 身份配置与记忆独立于供应商；记录实际模型版本 | 换模型后人格是否稳定仍需测试 |
| 费用 | 按用户消息汇总全部模型往返；缓存与未知用量分开 | 预留不是实际扣款，短窗口降幅不等于账单降幅 |
| 阅读与笔记 | 提供当前页/选段与可回源笔记，共用记忆入口 | 读到一页不是读完整本书 |
| 视频 | 丢弃过期帧与旧回合音频；观察与发言分开 | 文字观察不能恢复未保存的画面 |
| 手机 | 服务端任务继续、客户端恢复同步 | 浏览器前台测试不能保证锁屏通话 |
| 时间地点 | 记录时间、事件时间、位置依据分开；未知保留 | 日期标签不等于全库事件日期筛选 |
| 短窗口 | 普通少量近期消息、承接扩展、移出即恢复可检索 | 缩短窗口仍可能导致指代遗漏，需回归 |

后续必须建立每次变更的决策记录：问题、设计选择、替代方案、实现差异、验证结果、未解决风险、回退方法。避免只保留“完成啦”的更新日志。
